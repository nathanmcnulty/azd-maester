# Backlog

Use [the task list](docs/backlog.md) and its [canonical JSON](docs/backlog.json).

The Markdown view is generated. Edit the JSON, then regenerate the view using the reference tooling. Existing TODO, roadmap and execution files retain design and historical evidence; their remaining work is reconciled through this backlog.

Before claiming work, read applicable instructions, check current source, active worktree owners and dependencies. `proposed` is an idea awaiting selection; `ready` is bounded local work. A backlog status never authorizes live deployment, tenant writes, delivery, publication, merges, cleanup or required-check changes.
